How the daily number works, and how to fix a wrong entry.

The home number is not the monthly pool

Today = (monthly pool − active fixed bills) ÷ days in the billing cycle. A pool of 7,500 with 3,500 in fixed bills shows 4,000 on the cycle card, then about 133.3 a day in a 30-day cycle. The settings preview uses the same formula.

Don’t log a fixed bill twice

Rent and subscriptions belong in Fixed Bills. They are already removed from the pool. Logging them again with Log Spend counts the same money twice.

Edit or delete an entry

Tap the row on Today, then Save or Delete this entry. Long-press the row for the same actions. To backfill, open History, tap that day, and use Log this day.

Widget

−5, −15, and −30 write an expense the next time you open the app, category Other. They count toward the 100 free entries. After that, the buttons stop recording until SpendZen Pro is unlocked.

If you delete the app

The ledger is stored only on the iPhone. There is no account to restore it. Export CSV or JSON from Settings before you delete the app. Export is part of SpendZen Pro.
